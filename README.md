## CampusBids
CampusBids — це вебплатформа для студентів, що проживають у гуртожитках ЛНУ ім. Івана Франка, для купівлі та продажу вживаних речей у форматі аукціону. Студенти старших курсів отримують можливість швидко позбутись непотрібних меблів, техніки, чи підручників, а першокурсники — знайти все необхідне для проживання, не виходячи з кімнати.
